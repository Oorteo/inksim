# InkSim

InkSim is an interactive embroidery simulator and preview renderer. It shows
stitch order, thread colors, jumps, trims, and commands before production.

The application can replay a design stitch by stitch, inspect it at different
zoom levels, preview it on a procedural fabric background, and export PNG
previews.
